# Kivy APK Template

Готовый учебный шаблон для сборки Kivy-приложения в APK через GitHub Actions.

## Что нужно сделать ученику

1. Создать новый репозиторий из этого шаблона.
2. Заменить файл `main.py` своим приложением.
3. Открыть вкладку **Actions**.
4. Выбрать **Build Android APK**.
5. Нажать **Run workflow**.
6. После успешной сборки скачать архив **android-apk** из раздела **Artifacts**.
7. Распаковать архив и установить файл `.apk` на Android.

## Важно

Основной файл приложения должен называться строго `main.py`.

В корне репозитория обязательно должны находиться:

- `main.py`
- `buildozer.spec`
- папка `.github/workflows`

Если приложение использует изображения или дополнительные файлы, их тоже нужно загрузить в репозиторий.

Для изменения названия приложения откройте `buildozer.spec` и измените строку `title = My First App`.

Техническое имя `package.name` пишется маленькими латинскими буквами, без пробелов.
